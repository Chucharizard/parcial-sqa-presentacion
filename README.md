Abrir la presentación: https://chucharizard.github.io/parcial-sqa-presentacion/

- Avanza con las flechas del teclado.

Las capturas de JaCoCo, Docker Desktop y la API salen de la ejecución del equipo. Esta página es independiente del repositorio de código y no necesita instalar nada.
